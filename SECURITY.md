# Security policy

## Supported versions

The current 0.1.x line receives security fixes. This is an educational
diagnostic tool, not a production support commitment.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository when it is
enabled. If it is unavailable, contact the repository owner privately before
public disclosure. Do not place real credentials, private reports, journal
messages, hostnames, or network details in a public issue.

Include the affected version, operating system, minimal reproduction, impact,
and whether the behavior occurs in normal collection or only in the isolated
lab. See [Safety and limitations](docs/security.md) for the intended trust
boundaries.
